# 小米 SU7 Ultra · 360° 3D 展厅与工程透视实验室

在线访问（GitHub Pages）：<https://lovegrapejelly147.github.io/su7-ultra-360/>

## 功能特性

- **360° 沉浸式 3D 官网展厅**：支持触摸与鼠标自由环绕缩放、7 组精选视角、5 款官方金属清漆车漆（闪电黄 / 太空银 / 珍珠白 / 曜石黑 / 鹦鹉绿）、3 套影棚光影环境（暗调展厅 / 白棚工程 / 夜赛维修），以及水滴矩阵大灯、全宽光环尾灯、碳纤维双风道机盖、1,560 mm 固定式 GT 尾翼/电动尾翼与赛道拉花控制。
- **工程透视实验室**：支持 **透视 X-Ray**、**拆解 Explode（0–100%）**、**剖视 Cutaway（0–100%）** 与智能防重叠 3D 标注，展示前 HyperEngine V6s、双后 HyperEngine V8s（含铜线定子与旋转转子）、宁德时代麒麟 II 93.7 kWh 电池包、897 V 高压线束、悬架及 430 mm / 410 mm 碳陶制动系统与 Akebono 卡钳。
- **1,548 PS 实时物理求解器**：模拟新手/运动/赛道/排位 4 档动力、0–350 km/h 巡航、弹射加速、350→0 碳陶制动热力学黑体辐射发光、3D 气动流线与热衰极限保护。
- **本地 `.glb` / `.gltf` 替换**：支持拖入或选择自定义 3D 车辆模型自动等比缩放并贴地展示。

## 本地重建

```bash
node build.mjs
```
